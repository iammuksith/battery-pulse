# Battery Pulse
***Battery Pulse*** is a lightweight, privacy-first Android app that gives you useful information about your device's battery - clearly, locally, and without unnecessary permissions.

## Features
- Battery percentage
- Charging / discharging status
- Battery temperature
- Battery health/status when available
- Battery technology
- Voltage and other available battery information
- Automatically responds to battery and power-state changes
- Clean, responsive interface that follows the phone's system theme

## Privacy First
- No account
- No telemetry
- No unnecessary data collection
- No network connection required
- Works entirely offline
- Battery information stays on your device
- No unnecessary background services
- Designed to use very little battery and RAM

## Security & Transparency
*Battery Pulse* is **open source**, allowing anyone to inspect its code and understand how it works.

The app is designed to keep battery information local and avoid unnecessary system access.

## Battery Monitoring
*Battery Pulse* can provide useful battery information while keeping its own resource usage minimal.

On supported Android devices, battery information may include temperature, health/status, voltage, technology, and other metrics exposed by the system.

Available information can vary depending on the **device, manufacturer, hardware, and Android version**.
